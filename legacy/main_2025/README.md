# Historical main checkout

These scripts, images, instance masks, stimulus sources and old `output/`
artifacts were moved together from the repository root without changing their
contents. They preserve the earlier main implementation, including its original
relative paths. Run historical commands from this directory (`cd legacy/main_2025`)
with their original dependencies. Current experiments use `bwlab/` instead.

`mask_fragmenter_clean.py` here is the older main version. The separately frozen
baseline used by the current adapter lives in `../contour_fragmentation/`.
Current Vulcan downloads and run artifacts belong in the root `outputs/` folder.
